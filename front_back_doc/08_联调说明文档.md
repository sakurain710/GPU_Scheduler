# 联调说明文档

## 1. 文档目标
- 统一前后端联调入口与环境约定。
- 明确可直接用于联调的账号、权限与接口状态。

## 2. API Base URL

### 2.1 本地默认地址
- `http://localhost:8080`

### 2.2 接口前缀约定
- 认证：`/api/auth/*`
- GPU：`/api/gpus/*`（兼容 `/api/gpu/*`）
- 任务：`/api/tasks/*`（兼容 `/api/task/*`）
- 运维：`/api/ops/*`
- RBAC：`/api/users/*`、`/api/roles/*`、`/api/rbac/*`
- 监控：`/api/health`、`/api/metrics`

## 3. Swagger / OpenAPI 地址
- Swagger UI：`http://localhost:8080/swagger-ui/index.html`
- OpenAPI JSON：`http://localhost:8080/v3/api-docs`

## 4. 测试账号与角色账号

### 4.1 账号来源
- 来源脚本：`docs/mysql/gpu_scheduler_db/seed_data.sql`
- 说明：脚本注释声明测试明文密码为 `password`（BCrypt 已预置）。

### 4.2 账号清单

| 用途 | 用户名 | 角色 | 建议用途 |
|---|---|---|---|
| 管理员联调 | `admin` | `ROLE_ADMIN` | 全模块联调（含运维、监控、RBAC） |
| 审批流联调 | `reviewer` | `ROLE_TASK_REVIEWER` | 待审批列表、审批通过/拒绝 |
| 普通用户联调 | `normal` | `ROLE_USER` | 提交任务、查看/取消本人任务 |

### 4.3 账号安全说明
- 当前账号仅用于测试环境。
- 上线环境必须替换默认密码并重新初始化账号策略。

## 5. 跨域说明（CORS）
- 后端 CORS 配置：
- `allowedOriginPatterns = *`
- `allowedMethods = GET,POST,PUT,DELETE,OPTIONS,PATCH`
- `allowedHeaders = *`
- `allowCredentials = false`
- `exposedHeaders = X-RateLimit-Remaining, Retry-After`

联调影响：
- 前端可跨域访问，但应采用 Bearer Token 方案，不依赖 Cookie 凭据。

## 6. 接口完成状态

### 6.1 模块级完成状态

| 模块 | 状态 | 说明 |
|---|---|---|
| 认证模块 | `✅ 已完成` | 登录、刷新、登出、当前用户 |
| 任务模块 | `✅ 已完成` | 提交、我的任务、详情、取消、审批 |
| GPU模块 | `✅ 已完成` | 列表、详情、注册、状态更新、删除、心跳、指标 |
| 运维模块 | `✅ 已完成` | 调度控制、熔断重置、DLQ、强制处置 |
| 监控模块 | `✅ 已完成` | `/api/health`、`/api/metrics`、WebSocket遥测 |
| RBAC模块 | `✅ 已完成` | 用户管理、角色管理、资源/权限字典 |

### 6.2 完成边界说明
- `⚠️ 已实现但为模拟执行`：任务执行链路由 `TaskExecutionSimulator` 驱动，不是实际 GPU worker 执行。
- `⚠️ 权限字典初始化依赖`：`resource/permission` 完整初始化数据需按环境补齐，否则权限字典可能为空或不完整。

## 7. 联调步骤建议（最小闭环）
1. 初始化数据库：执行 `gpu_scheduler_db.sql` + `seed_data.sql`。
2. 配置环境变量（DB/Redis/JWT，敏感值请自管，不写入仓库）。
3. 启动后端：`mvn spring-boot:run`。
4. 先用 `admin` 登录，验证认证与基础模块连通。
5. 再用 `normal/reviewer` 走任务提交与审批闭环。
6. 最后验证监控与运维接口。

## 8. 联调检查清单
- [ ] 登录成功可拿到 access/refresh token
- [ ] 受保护接口携带 Bearer token 可访问
- [ ] 普通用户仅可见本人任务
- [ ] 审批账号可访问待审批并执行通过/拒绝
- [ ] GPU管理写操作仅授权用户可执行
- [ ] 监控接口与 WebSocket 订阅可用
- [ ] 运维接口可读取并处置 DLQ
