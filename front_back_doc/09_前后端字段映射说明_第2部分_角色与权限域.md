# 前后端字段映射说明（第2部分：角色与权限域）

## 1. 范围
- 后端来源：`RoleController`、`RbacDictionaryController`、`dto/role/*`、`entity/Permission`、`entity/Resource`。
- 前端范围：角色管理页、角色授权弹窗、角色绑定用户弹窗、权限/资源字典下拉加载。

## 2. 角色管理字段映射（`/api/roles`）

### 2.1 创建角色 `POST /api/roles`
请求（`CreateRoleRequest`）映射：

| 前端字段 | 后端字段 | 类型 | 必填 | 校验/默认 |
|---|---|---|---|---|
| `code` | `CreateRoleRequest.code` | string | 是 | `@NotBlank`，最大50 |
| `name` | `CreateRoleRequest.name` | string | 是 | `@NotBlank`，最大100 |
| `description` | `CreateRoleRequest.description` | string | 否 | 角色说明 |
| `roleType` | `CreateRoleRequest.roleType` | number | 否 | 默认 `1` |
| `status` | `CreateRoleRequest.status` | number | 否 | 默认 `1`（启用） |
| `sortOrder` | `CreateRoleRequest.sortOrder` | number | 否 | 默认 `0` |
| `parentRoleId` | `CreateRoleRequest.parentRoleId` | number | 否 | 父角色ID |
| `permissionIds` | `CreateRoleRequest.permissionIds` | number[] | 否 | 初始权限ID列表 |


响应 `data`（`RoleResponse`）映射：

| 前端字段 | 后端字段 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `id` | `RoleResponse.id` | number | 是 | 角色ID |
| `code` | `RoleResponse.code` | string | 是 | 角色编码 |
| `name` | `RoleResponse.name` | string | 是 | 角色名称 |
| `description` | `RoleResponse.description` | string | 否 | 描述 |
| `roleType` | `RoleResponse.roleType` | number | 否 | 角色类型 |
| `status` | `RoleResponse.status` | number | 是 | `0=禁用,1=启用` |
| `sortOrder` | `RoleResponse.sortOrder` | number | 否 | 排序值 |
| `parentRoleId` | `RoleResponse.parentRoleId` | number | 否 | 父角色ID |
| `permissionIds` | `RoleResponse.permissionIds` | number[] | 否 | 权限ID列表 |
| `createdAt` | `RoleResponse.createdAt` | string | 否 | ISO-8601 |
| `updatedAt` | `RoleResponse.updatedAt` | string | 否 | ISO-8601 |

### 2.3 删除角色 `DELETE /api/roles/{roleId}`

### 2.4 角色详情 `GET /api/roles/{roleId}`

## 3. 角色授权/绑定字段映射

### 3.1 分配角色权限 `POST /api/roles/{roleId}/permissions`

| 前端字段 | 后端字段 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `roleId` | 路径参数 `@PathVariable roleId` | number | 是 | 路径角色ID |
| `roleId` | `AssignPermissionsRequest.roleId` | number | 是 | 请求体角色ID（建议与路径一致） |
| `permissionIds` | `AssignPermissionsRequest.permissionIds` | number[] | 是 | 目标权限ID列表 |


响应 `data`：`null`。

### 3.2 撤销角色权限 `DELETE /api/roles/{roleId}/permissions`
请求体沿用 `AssignPermissionsRequest`，字段同 3.1。

### 3.3 分配角色用户 `POST /api/roles/{roleId}/users`

| 前端字段 | 后端字段 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `roleId` | 路径参数 `@PathVariable roleId` | number | 是 | 路径角色ID |
| `roleId` | `AssignUsersRequest.roleId` | number | 是 | 请求体角色ID（建议与路径一致） |
| `userIds` | `AssignUsersRequest.userIds` | number[] | 是 | 用户ID列表 |
| `expiresAt` | `AssignUsersRequest.expiresAt` | string(datetime) | 否 | 绑定过期时间 |


响应 `data`：`null`。

### 3.4 解除角色用户绑定 `DELETE /api/roles/{roleId}/users`
请求体沿用 `AssignUsersRequest`；服务层使用 `roleId + userIds` 执行解绑。

## 5. 前端实现约定
- 角色授权与角色绑人接口同时存在路径 `roleId` 与 body `roleId`，前端应保持一致，避免后端一致性校验失败。
- RBAC 字典建议在页面初始化阶段缓存，并按 `status=1` 作为默认查询条件。
- `permissionIds`、`userIds` 均为数字数组，提交前应去重并过滤空值。
