# 接口文档（第6部分）：任务管理接口

## 1. 文档范围
- 控制器：`GpuTaskController`
- 路径前缀：`/api/task` 与 `/api/tasks`（兼容别名）
- 覆盖接口：提交任务、任务详情、我的任务列表、取消任务、审批列表、审批通过、审批拒绝

## 2. 路径与权限约定

### 2.1 路径约定
- 当前后端同时支持：`/api/task/*` 与 `/api/tasks/*`
- 文档推荐使用：`/api/tasks/*`
- 兼容路径：`/api/task/*`

### 2.2 权限要求
- 控制器默认仅要求已认证用户。
- 审批接口增加权限控制：
- `GET /approval/pending`：`ROLE_ADMIN` / `ROLE_TASK_REVIEWER` / `task:approval:read`
- `POST /{taskId}/approve`、`POST /{taskId}/reject`：`ROLE_ADMIN` / `ROLE_TASK_REVIEWER` / `task:approval:review`
- `GET /{taskId}`、`POST /{taskId}/cancel`：服务层校验“任务所有者或审批角色”。

### 2.3 统一响应结构（Result）

| 字段 | 类型 | 含义 | 可空 | 默认值 |
|---|---|---|---|---|
| code | Integer | 业务状态码 | 否 | 成功时 `200` |
| errorCode | String | 业务错误码 | 是 | `null` |
| message | String | 响应消息 | 否 | 成功时通常为`操作成功` |
| data | Object | 业务数据 | 是 | `null` |

### 2.4 常见错误码

| HTTP | errorCode | 场景 |
|---|---|---|
| 400 | `null` | 参数校验失败 |
| 401 | `AUTH_UNAUTHORIZED` | 未认证 |
| 403 | `null` | 无审批权限访问审批接口 |
| 403 | `TASK_FORBIDDEN` | 非所有者且无审批角色访问任务 |
| 404 | `RESOURCE_NOT_FOUND` | 任务不存在 |
| 409 | `INVALID_TASK_STATE` | 非法状态迁移（如终态任务再审批） |
| 429 | `TASK_ACTIVE_LIMIT_EXCEEDED` | 普通用户活动任务超上限 |

## 3. 数据结构

### 3.1 SubmitTaskRequest

| 字段 | 类型 | 含义 | 可空 | 默认值 | 约束 |
|---|---|---|---|---|---|
| title | String | 任务标题 | 否 | 无 | `@NotBlank`, max=128 |
| description | String | 任务描述 | 是 | `null` | max=65535 |
| taskType | String | 任务类型 | 否 | 无 | `@NotBlank`, max=64 |
| minMemoryGb | BigDecimal | 最低显存需求（GB） | 否 | 无 | `>0` |
| computeUnitsGflop | BigDecimal | 计算量（GFLOP） | 否 | 无 | `>0` |
| basePriority | Integer | 基础优先级 | 是 | `5` | `1-10` |

| 字段 | 类型 | 含义 | 可空 |
|---|---|---|---|
| id | Long | 任务ID | 否 |
| userId | Long | 提交用户ID | 是 |
| gpuId | Long | 分配GPU ID | 是 |
| title | String | 任务标题 | 否 |
| description | String | 任务描述 | 是 |
| taskType | String | 任务类型 | 否 |
| minMemoryGb | BigDecimal | 最低显存需求GB | 否 |
| computeUnitsGflop | BigDecimal | 计算量GFLOP | 否 |
| basePriority | Integer | 基础优先级 | 否 |
| status | Integer | 状态码 | 否 |
| statusLabel | String | 状态标签 | 否 |
| estimatedSeconds | BigDecimal | 预估耗时秒 | 是 |
| actualSeconds | BigDecimal | 实际耗时秒 | 是 |
| errorMessage | String | 错误/拒绝原因 | 是 |

| finishedAt | LocalDateTime | 完成时间 | 是 |
| createdAt | LocalDateTime | 创建时间 | 否 |

### 3.3 任务状态枚举

| 状态码 | 标签 |
|---|---|
| 1 | Pending |
| 2 | Queued |
| 3 | Running |
| 4 | Completed |
| 5 | Failed |
| 6 | Cancelled |
| 7 | Pending Approval |
| 8 | Rejected |

## 4. 接口明细

---

### 4.1 提交GPU任务
- **方法**：`POST`
- **路径**：`/api/tasks/submit`
- **兼容路径**：`/api/task/submit`

#### 业务规则
- 默认优先级阈值：`basePriority >= 9` 且用户不在审批角色中时，任务进入 `PENDING_APPROVAL(7)`。
- 非审批角色用户活动任务数（`PENDING/PENDING_APPROVAL/QUEUED/RUNNING`）达到上限（默认 `3`）时拒绝提交。

#### 成功响应
- `data` 为 `TaskResponse`。

#### 成功示例
```json
{
  "code": 200,
  "errorCode": null,
  "message": "任务提交成功",
  "data": {
    "id": 2001,
    "userId": 12,
    "gpuId": null,
    "title": "Train LLM",
    "description": "phase-1",
    "taskType": "TRAINING",
    "minMemoryGb": 16,
    "computeUnitsGflop": 15000,
    "basePriority": 5,
    "status": 2,
    "statusLabel": "Queued",
    "estimatedSeconds": null,
    "actualSeconds": null,
    "errorMessage": null,
    "enqueueAt": "2026-04-03T13:00:00",
    "dispatchedAt": null,
    "estimatedFinishAt": null,
    "finishedAt": null,
    "createdAt": "2026-04-03T13:00:00"
  }
}
```

#### 失败示例（活动任务超限）
```json
{
  "code": 429,
  "errorCode": "TASK_ACTIVE_LIMIT_EXCEEDED",
  "message": "Active task limit exceeded, please wait for running tasks to finish",
  "data": null
}
```

### 4.2 获取任务详情
- **方法**：`GET`
- **路径**：`/api/tasks/{taskId}`
- **兼容路径**：`/api/task/{taskId}`

#### 权限语义
- 任务所有者可查。
- 审批角色（`approverRoles`）可查任意任务。

#### 失败示例（无权查看）
```json
{
  "code": 403,
  "errorCode": "TASK_FORBIDDEN",
  "message": "No permission to access this task",
  "data": null
}
```

---

### 4.3 列出我的任务
- **方法**：`GET`
- **路径**：`/api/tasks/my`
- **兼容路径**：`/api/task/my`

#### 查询参数

| 字段 | 类型 | 含义 | 可空 | 默认值 | 约束 |
|---|---|---|---|---|---|
| page | Integer | 页码（从1开始） | 是 | `1` | `@Min(1)` |
| size | Integer | 每页大小 | 是 | `10` | `@Min(1)`, `@Max(200)` |
| status | Integer | 状态过滤 | 是 | `null` | 参考状态枚举 |
| sortBy | String | 排序字段 | 是 | `createdAt` | `createdAt/basePriority/enqueueAt/status/id` |
| sortDir | String | 排序方向 | 是 | `desc` | `asc/desc` |

#### 成功响应
- `data` 为 `IPage<TaskResponse>`，包含 `records/total/size/current/pages`。

---

### 4.4 取消任务
- **方法**：`POST`
- **路径**：`/api/tasks/{taskId}/cancel`
- **兼容路径**：`/api/task/{taskId}/cancel`

#### 业务规则
- 仅任务所有者或审批角色可操作。
- 取消动作本质为状态迁移到 `CANCELLED(6)`，受状态机约束。

#### 失败示例（非法状态迁移）
```json
{
  "code": 409,
  "errorCode": "INVALID_TASK_STATE",
  "message": "非法状态转换: Completed(4) → Cancelled(6)",
  "data": null
}
```

---

### 4.5 待审批任务列表
- **方法**：`GET`
- **路径**：`/api/tasks/approval/pending`
- **兼容路径**：`/api/task/approval/pending`
- **权限**：`ROLE_ADMIN` / `ROLE_TASK_REVIEWER` / `task:approval:read`

#### 查询参数

| 字段 | 类型 | 含义 | 可空 | 默认值 |
|---|---|---|---|---|
| page | Integer | 页码 | 是 | `1` |
| size | Integer | 每页大小 | 是 | `10` |
| sortBy | String | 排序字段 | 是 | `createdAt` |
| sortDir | String | 排序方向 | 是 | `asc` |

#### 成功响应
- `data` 为 `IPage<TaskResponse>`，仅 `status = PENDING_APPROVAL(7)`。

---

### 4.6 审批通过任务
- **方法**：`POST`
- **路径**：`/api/tasks/{taskId}/approve`
- **兼容路径**：`/api/task/{taskId}/approve`
- **权限**：`ROLE_ADMIN` / `ROLE_TASK_REVIEWER` / `task:approval:review`

#### 业务规则
- 触发状态迁移到 `QUEUED(2)`。
- 非待审批状态调用时会触发 `INVALID_TASK_STATE`。

#### 成功响应
- `data` 为更新后的 `TaskResponse`。

---

### 4.7 审批拒绝任务
- **方法**：`POST`
- **路径**：`/api/tasks/{taskId}/reject`
- **兼容路径**：`/api/task/{taskId}/reject`
- **权限**：`ROLE_ADMIN` / `ROLE_TASK_REVIEWER` / `task:approval:review`

#### 请求体（RejectTaskRequest，可选）

| 字段 | 类型 | 含义 | 可空 | 默认值 |
|---|---|---|---|---|
| reason | String | 拒绝原因 | 是 | `null` |

#### 业务规则
- 若 `reason` 非空，写入任务 `errorMessage`。
- 状态迁移到 `REJECTED(8)`。

#### 成功示例
```json
{
  "code": 200,
  "errorCode": null,
  "message": "操作成功",
  "data": {
    "id": 2002,
    "status": 8,
    "statusLabel": "Rejected",
    "errorMessage": "资源预算不足"
  }
}
```

## 5. 状态流转约束（与接口强相关）
- `PENDING -> QUEUED/CANCELLED`
- `PENDING_APPROVAL -> QUEUED/REJECTED/CANCELLED`
- `QUEUED -> RUNNING/CANCELLED`
- `RUNNING -> COMPLETED/FAILED/QUEUED`
- `FAILED -> QUEUED`
- 终态：`COMPLETED/CANCELLED/REJECTED`（不可再迁移）

## 6. 联调注意事项
- 路径存在单复数兼容别名，建议统一使用 `/api/tasks`。
- 高优任务自动审批策略依赖配置：`task-submission.high-priority-threshold` 与 `approver-roles`。
- `createdAt/enqueueAt/dispatchedAt/...` 时间序列化格式：`yyyy-MM-dd HH:mm:ss`（时区：`Asia/Shanghai`）。
