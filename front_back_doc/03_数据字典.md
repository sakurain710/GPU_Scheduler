## 用户与RBAC域


## 1. 范围
- 数据库来源：`docs/mysql/gpu_scheduler_db/gpu_scheduler_db.sql`、`seed_data.sql`
- 实体来源：`entity/User.java`、`Role.java`、`Permission.java`、`Resource.java`、`UserRole.java`、`RolePermission.java`
- 本部分覆盖：`user`、`role`、`resource`、`permission`、`user_role`、`role_permission`

## 2. user（用户表）

### 2.1 表说明
- 主键：`id`
- 唯一约束：`username`、`email`
- 软删除字段：`deleted_at`

### 2.2 字段字典

| 字段 | 类型 | 可空 | 默认值 | 含义 |
|---|---|---|---|---|
| id | BIGINT UNSIGNED | 否 | 自增 | 用户ID |
| username | VARCHAR(64) | 否 | - | 登录名（唯一） |
| password | VARCHAR(255) | 否 | - | 密码哈希 |
| nickname | VARCHAR(64) | 是 | NULL | 昵称 |
| email | VARCHAR(128) | 是 | NULL | 邮箱（唯一） |
| mobile | VARCHAR(20) | 是 | NULL | 手机号 |
| avatar | VARCHAR(500) | 是 | NULL | 头像URL |
| gender | TINYINT UNSIGNED | 否 | 0 | 性别 |
| user_type | TINYINT UNSIGNED | 否 | 1 | 用户类型 |
| status | TINYINT UNSIGNED | 否 | 1 | 账号状态 |
| login_ip | VARCHAR(50) | 是 | NULL | 最近登录IP |
| login_at | DATETIME | 是 | NULL | 最近登录时间 |
| pwd_reset_at | DATETIME | 是 | NULL | 最近密码重置时间 |
| remark | VARCHAR(500) | 是 | NULL | 备注 |
| created_by | BIGINT UNSIGNED | 是 | NULL | 创建人ID（FK user.id） |
| created_at | DATETIME | 否 | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | 否 | CURRENT_TIMESTAMP ON UPDATE | 更新时间 |
| deleted_at | DATETIME | 是 | NULL | 软删除时间 |

### 2.3 枚举值
- `gender`: `0=Unknown`, `1=Male`, `2=Female`
- `user_type`(SQL注释): `1=Normal`, `2=Reviewer`, `3=Admin`
- `status`: `1=Active`, `0=Disabled`, `2=Locked`

### 2.4 索引/约束
- `uq_user_username`、`uq_user_email`
- `idx_user_mobile`、`idx_user_deleted`
- CHECK：`gender/user_type/status` 合法值约束

## 2. gpu（GPU资源表）

### 2.1 表说明
- 主键：`id`
- 外键：`created_by -> user.id`
- 软删除字段：`deleted_at`

### 2.2 字段字典

| 字段 | 类型 | 可空 | 默认值 | 含义 |
|---|---|---|---|---|
| id | BIGINT UNSIGNED | 否 | 自增 | GPU ID |
| name | VARCHAR(128) | 否 | - | GPU型号名称 |
| manufacturer | VARCHAR(64) | 否 | - | 制造商 |
| memory_gb | DECIMAL(8,2) | 否 | - | 显存容量（GB） |
| computing_power_tflops | DECIMAL(10,4) | 否 | - | 峰值算力（TFLOPS） |
| status | TINYINT UNSIGNED | 否 | 1 | GPU状态 |
| remark | VARCHAR(500) | 是 | NULL | 备注 |
| created_by | BIGINT UNSIGNED | 是 | NULL | 创建人ID |
| created_at | DATETIME | 否 | CURRENT_TIMESTAMP | 创建时间 |

### 2.3 枚举值
- `status`: `1=Idle`, `2=Busy`, `3=Offline`, `4=Maintenance`

## 3. gpu_task（任务表）

### 3.1 表说明
- 主键：`id`
- 外键：`user_id -> user.id`（SET NULL）、`gpu_id -> gpu.id`（RESTRICT）
- 软删除字段：`deleted_at`

### 3.2 字段字典

| 字段 | 类型 | 可空 | 默认值 | 含义 |
|---|---|---|---|---|
| id | BIGINT UNSIGNED | 否 | 自增 | 任务ID |
| user_id | BIGINT UNSIGNED | 是 | NULL | 提交用户ID |
| gpu_id | BIGINT UNSIGNED | 是 | NULL | 分配GPU ID |
| title | VARCHAR(128) | 否 | - | 任务标题 |
| description | TEXT | 是 | NULL | 任务描述 |
| task_type | VARCHAR(64) | 否 | - | 任务类型 |
| min_memory_gb | DECIMAL(8,2) | 否 | - | 最低显存需求（GB） |
| compute_units_gflop | DECIMAL(16,4) | 否 | - | 计算量（GFLOP） |
| base_priority | TINYINT UNSIGNED | 否 | 5 | 基础优先级（1-10） |
| enqueue_at | DATETIME(3) | 否 | CURRENT_TIMESTAMP(3) | 入队时间 |
| dispatched_at | DATETIME(3) | 是 | NULL | 派发时间 |
| estimated_finish_at | DATETIME(3) | 是 | NULL | 预计完成时间 |
| finished_at | DATETIME(3) | 是 | NULL | 完成时间 |
| estimated_seconds | DECIMAL(12,4) | 是 | NULL | 预估耗时秒 |
| actual_seconds | DECIMAL(12,4) | 是 | NULL | 实际耗时秒 |
| status | TINYINT UNSIGNED | 否 | 1 | 任务状态 |
| error_message | TEXT | 是 | NULL | 失败或拒绝原因 |
| created_at | DATETIME | 否 | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | 否 | CURRENT_TIMESTAMP ON UPDATE | 更新时间 |
| deleted_at | DATETIME | 是 | NULL | 软删除时间 |

### 3.3 枚举值
- `status`:
- `1=Pending`
- `2=Queued`
- `3=Running`
- `4=Completed`
- `5=Failed`
- `6=Cancelled`
- `7=PendingApproval`
- `8=Rejected`

### 3.4 约束与索引
- CHECK：`status in (1..8)`
- CHECK：`task_type in ('model_training','inference','rendering')`
- CHECK：`base_priority between 1 and 10`
- CHECK：`min_memory_gb > 0`
- CHECK：`compute_units_gflop > 0`
- CHECK：`estimated_seconds/actual_seconds` 若非空需大于0
- 索引：
- `idx_task_user`
- `idx_task_gpu`
- `idx_task_status`
- `idx_task_status_enqueue`
- `idx_task_user_status_created`
- `idx_task_queue (status, base_priority DESC, enqueue_at)`
- `idx_task_deleted`

## 4. gpu_task_log（任务审计日志表）

### 4.1 表说明
- 主键：`id`
- 外键：`task_id -> gpu_task.id`（CASCADE）、`gpu_id -> gpu.id`（SET NULL）、`operator_id -> user.id`（SET NULL）
- 用途：记录任务状态变化与运维动作

### 4.2 字段字典

| 字段 | 类型 | 可空 | 默认值 | 含义 |
|---|---|---|---|---|
| id | BIGINT UNSIGNED | 否 | 自增 | 日志ID |
| task_id | BIGINT UNSIGNED | 否 | - | 关联任务ID |
| gpu_id | BIGINT UNSIGNED | 是 | NULL | 关联GPU ID |
| event | VARCHAR(32) | 否 | - | 事件名 |
| old_status | TINYINT UNSIGNED | 是 | NULL | 变更前状态 |
| new_status | TINYINT UNSIGNED | 是 | NULL | 变更后状态 |
| age_delta | DECIMAL(8,4) | 是 | NULL | 老化增量（当前实现未使用） |
| detail | TEXT | 是 | NULL | 详情 |
| operator_id | BIGINT UNSIGNED | 是 | NULL | 操作人ID |
| created_at | DATETIME | 否 | CURRENT_TIMESTAMP | 事件时间 |

### 4.3 状态约束
- `old_status/new_status` 允许 `NULL` 或 `1..8`

### 4.4 事件值
- 命名规范：`UPPER_SNAKE_CASE`（全大写下划线）
- 允许值（数据库 CHECK + 代码枚举）：`QUEUED`、`DISPATCHED`、`COMPLETED`、`FAILED`、`CANCELLED`、`PENDING_APPROVAL`、`REJECTED`
- 不允许自定义自由字符串

## 5. 时间/数值格式规则
- 时间字段使用 MySQL `DATETIME` 或 `DATETIME(3)`，Java 侧映射为 `LocalDateTime`。
- JSON 序列化统一采用 `yyyy-MM-dd HH:mm:ss`，时区统一 `Asia/Shanghai`。
- 百分比/比率字段不在本部分表内持久化，通常为服务层实时计算。

## 6. 实体映射对照（Java）
- 表 `gpu` -> 实体 `Gpu`
- 表 `gpu_task` -> 实体 `GpuTask`
- 表 `gpu_task_log` -> 实体 `GpuTaskLog`

## 7. 事件规范结论
- `gpu_task_log.event` 已明确为受控枚举值，不接受自定义事件字符串。
- 规范来源：`TaskStateMachine.resolveEvent` + 数据库 `chk_log_event` 约束。
