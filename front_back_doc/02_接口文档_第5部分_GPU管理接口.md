# 接口文档（第5部分）：GPU管理接口

## 1. 文档范围
- 控制器：`GpuController`
- 路径前缀：`/api/gpu` 与 `/api/gpus`（兼容别名）
- 覆盖接口：GPU列表/详情/注册/状态更新/删除/健康摘要/利用率指标/心跳

## 2. 路径与权限约定

### 2.1 路径约定
- 当前后端同时支持：`/api/gpu/*` 与 `/api/gpus/*`
- 文档推荐使用：`/api/gpus/*`
- 兼容路径：`/api/gpu/*`

### 2.2 权限要求
- 控制器未加类级 `@PreAuthorize`，但部分接口有方法级鉴权：
- `POST /`、`PUT /{gpuId}/status`、`DELETE /{gpuId}`：`ROLE_ADMIN` 或 `gpu:write`
- `GET /health`、`GET /metrics`：`ROLE_ADMIN` 或 `gpu:read`
- `POST /{gpuId}/heartbeat`：`ROLE_ADMIN` 或 `gpu:heartbeat`
- `GET /`、`GET /{gpuId}`：当前代码未配置方法级权限（仅需通过全局认证）

### 2.3 统一响应结构（Result）

| 字段 | 类型 | 含义 | 可空 | 默认值 |
|---|---|---|---|---|
| code | Integer | 业务状态码 | 否 | 成功时 `200` |
| errorCode | String | 业务错误码 | 是 | `null` |
| message | String | 响应消息 | 否 | 成功时通常为`操作成功` |
| data | Object | 业务数据 | 是 | `null` |

### 2.4 常见错误码

| HTTP | errorCode | 场景 |
|---|---|---|
| 400 | `null` | 参数校验失败 |
| 400 | `GPU_BUSY` | GPU忙碌时禁止手工改状态/删除 |
| 401 | `AUTH_UNAUTHORIZED` | 未认证 |
| 403 | `null` | 权限不足 |
| 404 | `RESOURCE_NOT_FOUND` | GPU不存在 |

## 3. 数据结构

### 3.1 GpuResponse

| 字段 | 类型 | 含义 | 可空 | 备注 |
|---|---|---|---|---|
| id | Long | GPU ID | 否 | 主键 |
| name | String | 型号名称 | 否 | 例如 `NVIDIA A100 80GB` |
| manufacturer | String | 制造商 | 否 | 例如 `NVIDIA` |
| memoryGb | BigDecimal | 显存（GB） | 否 | >0 |
| computingPowerTflops | BigDecimal | 算力（TFLOPS） | 否 | >0 |
| status | Integer | 状态码 | 否 | `1=IDLE,2=BUSY,3=OFFLINE,4=MAINTENANCE` |
| statusLabel | String | 状态文本 | 否 | `Idle/Busy/Offline/Maintenance` |
| remark | String | 备注 | 是 | - |
| createdBy | Long | 创建人ID | 是 | 注册接口写入 |
| createdAt | LocalDateTime | 创建时间 | 否 | 序列化格式待确认 |
| updatedAt | LocalDateTime | 更新时间 | 否 | 序列化格式待确认 |

## 4. 接口明细

### 4.1 列出GPU（分页）
- **方法**：`GET`
- **路径**：`/api/gpus`
- **兼容路径**：`/api/gpu`

#### 查询参数

| 字段 | 类型 | 含义 | 可空 | 默认值 | 约束 |
|---|---|---|---|---|---|
| page | Integer | 页码（从1开始） | 是 | `1` | `@Min(1)` |
| size | Integer | 每页数量 | 是 | `20` | `@Min(1)`, `@Max(200)` |
| status | Integer | 状态过滤 | 是 | `null` | `1/2/3/4` |
| sortBy | String | 排序字段 | 是 | `id` | `id/name/memoryGb/computingPowerTflops/status/createdAt` |
| sortDir | String | 排序方向 | 是 | `asc` | `asc/desc` |

#### 成功响应 `data`
- 类型：`IPage<GpuResponse>`
- 关键字段：`records/total/size/current/pages`

#### 成功示例
```json
{
  "code": 200,
  "errorCode": null,
  "message": "操作成功",
  "data": {
    "records": [
      {
        "id": 1,
        "name": "NVIDIA A100 80GB",
        "manufacturer": "NVIDIA",
        "memoryGb": 80,
        "computingPowerTflops": 19.5,
        "status": 1,
        "statusLabel": "Idle",
        "remark": "rack-1",
        "createdBy": 1,
        "createdAt": "2026-04-03T10:00:00",
        "updatedAt": "2026-04-03T10:00:00"
      }
    ],
    "total": 1,
    "size": 20,
    "current": 1,
    "pages": 1
  }
}
```

- **方法**：`GET`
- **路径**：`/api/gpus/{gpuId}`
- **兼容路径**：`/api/gpu/{gpuId}`

#### 路径参数

| 字段 | 类型 | 含义 | 可空 |
|---|---|---|---|
| gpuId | Long | GPU ID | 否 |

#### 成功响应
- `data` 为 `GpuResponse`。

#### 失败示例（GPU不存在）
```json
{
  "code": 404,
  "errorCode": "RESOURCE_NOT_FOUND",
  "message": "GPU不存在: 999",
  "data": null
}
```

### 4.3 注册GPU
- **方法**：`POST`
- **路径**：`/api/gpus`
- **兼容路径**：`/api/gpu`
- **权限**：`ROLE_ADMIN` 或 `gpu:write`

#### 请求体（RegisterGpuRequest）

| 字段 | 类型 | 含义 | 可空 | 默认值 | 约束 |
|---|---|---|---|---|---|
| name | String | GPU型号名称 | 否 | 无 | `@NotBlank`, max=128 |
| manufacturer | String | 制造商 | 否 | 无 | `@NotBlank`, max=64 |
| memoryGb | BigDecimal | 显存GB | 否 | 无 | `@NotNull`, `>0` |
| computingPowerTflops | BigDecimal | 算力TFLOPS | 否 | 无 | `@NotNull`, `>0` |
| remark | String | 备注 | 是 | `null` | max=255 |

#### 行为说明
- 服务端会将新 GPU 状态初始化为 `IDLE(1)`。
- `createdBy` 取当前登录用户ID。

#### 成功示例
```json
{
  "code": 200,
  "errorCode": null,
  "message": "GPU注册成功",
  "data": {
    "id": 12,
    "name": "NVIDIA L40S",
    "manufacturer": "NVIDIA",
    "memoryGb": 48,
    "computingPowerTflops": 91.6,
    "status": 1,
    "statusLabel": "Idle",
    "remark": "rack-2",
    "createdBy": 1,
    "createdAt": "2026-04-03T12:00:00",
    "updatedAt": "2026-04-03T12:00:00"
  }
}
```

### 4.4 更新GPU状态
- **方法**：`PUT`
- **路径**：`/api/gpus/{gpuId}/status`
- **兼容路径**：`/api/gpu/{gpuId}/status`
- **权限**：`ROLE_ADMIN` 或 `gpu:write`

#### 请求体（UpdateGpuStatusRequest）

| 字段 | 类型 | 含义 | 可空 | 默认值 | 约束 |
|---|---|---|---|---|---|
| status | Integer | 新状态 | 否 | 无 | `@NotNull`, `1-4` |

#### 业务限制
- 当前状态为 `BUSY(2)` 时，禁止手工修改，返回 `GPU_BUSY`。

#### 失败示例（GPU忙碌）
```json
{
  "code": 400,
  "errorCode": "GPU_BUSY",
  "message": "GPU正在执行任务，不允许手动修改状态",
  "data": null
}
```

---

### 4.5 删除GPU
- **方法**：`DELETE`
- **路径**：`/api/gpus/{gpuId}`
- **兼容路径**：`/api/gpu/{gpuId}`
- **权限**：`ROLE_ADMIN` 或 `gpu:write`

#### 业务限制
- 当前状态为 `BUSY(2)` 时禁止删除，返回 `GPU_BUSY`。

#### 成功响应
```json
{
  "code": 200,
  "errorCode": null,
  "message": "操作成功",
  "data": null
}
```

### 4.6 GPU健康摘要
- **方法**：`GET`
- **路径**：`/api/gpus/health`
- **兼容路径**：`/api/gpu/health`
- **权限**：`ROLE_ADMIN` 或 `gpu:read`

#### 成功响应 `data`
- 类型：`Map<String,Long>`
- Key 为状态文本：`Idle/Busy/Offline/Maintenance`

```json
  "errorCode": null,
  "message": "操作成功",
  "data": {
    "Idle": 8,
    "Busy": 3,
    "Offline": 1,
    "Maintenance": 0
  }
}
```

### 4.7 GPU利用率指标
- **方法**：`GET`
- **路径**：`/api/gpus/metrics`
- **兼容路径**：`/api/gpu/metrics`
- **权限**：`ROLE_ADMIN` 或 `gpu:read`

#### 成功响应 `data`

| 字段 | 类型 | 含义 |
|---|---|---|
| total | Long | GPU总数 |
| busy | Long | Busy数量 |
| idle | Long | Idle数量 |
| utilizationRate | String | 利用率百分比字符串（如 `37.5%`） |

#### 示例
```json
{
  "code": 200,
  "errorCode": null,
  "message": "操作成功",
  "data": {
    "total": 12,
    "busy": 3,
    "idle": 8,
    "utilizationRate": "25.0%"
  }
}
```

### 4.8 上报GPU Worker心跳
- **方法**：`POST`
- **路径**：`/api/gpus/{gpuId}/heartbeat`
- **兼容路径**：`/api/gpu/{gpuId}/heartbeat`
- **权限**：`ROLE_ADMIN` 或 `gpu:heartbeat`

#### 行为说明
- 服务端写入心跳时间到 Redis。
- 若该 GPU 为 `OFFLINE`，可尝试恢复为 `IDLE`。

#### 成功响应 `data`

| 字段 | 类型 | 含义 |
|---|---|---|
| gpuId | Long | GPU ID |
| accepted | Boolean | 是否接收成功（固定 `true`） |
| heartbeatAgeSeconds | Integer | 心跳年龄秒数（当前返回 `0`） |

#### 成功示例
```json
{
  "code": 200,
  "errorCode": null,
  "message": "操作成功",
  "data": {
    "gpuId": 12,
    "accepted": true,
    "heartbeatAgeSeconds": 0
  }
}
```

## 5. 联调注意事项
- 路径存在单复数兼容别名，前端应统一选用 `/api/gpus`。
- `utilizationRate` 是字符串百分比，不是数值型（ECharts 如需数值需前端转换）。
- `GET /api/gpus` 与 `GET /api/gpus/{gpuId}` 当前未单独加方法级权限，仅依赖全局认证。
